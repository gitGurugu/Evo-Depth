# MetaWorld MT50 评测

MT50 是 50 个 Sawyer 操作任务。策略用 Evo-Depth 的 MetaWorld 权重，不要用 LIBERO 的 checkpoint。任务顺序、难度组和语言指令都在本目录的 `mt50_order.json`、`tasks.jsonl` 里，不用再 clone 仓库或下资源包。

每个任务默认 10 条 episode，单条最多 400 步，动作块长度 17。相机是 `corner2`。无显示器，渲染用 `MUJOCO_GL=egl`。

难度组：`easy`（28）、`medium`（11）、`hard`（6）、`very_hard`（5）。四组共用同一份权重。4 路 server 用 9000–9003。0 号卡放 easy、medium，1 号卡放 hard、very_hard。

不要动 `.venv`、`.venv-libero`、`.venv-libero-plus`。MetaWorld 用单独的 `.venv-metaworld`。先停掉还在跑的 LIBERO-PLUS server，9000 起的端口会被占用。停进程只杀对应 pid 文件里的 PID，不要 `pkill`。

实时预览是可选项。不传 `--preview_port` 就只存视频，不监听画面端口。开预览后，仿真每走一步就把该帧立刻推到页面，不再慢放。等策略返回动作时仿真本身是停的，画面也会停在上一帧。

MuJoCo 查看器画在四块虚拟桌面上，窗口用显卡画。`run_mt50_clients.sh` 默认不开。只在 client 命令末尾加 `--viewer` 也不够，桌面进程没在跑时窗口没有地方显示。

先起桌面（重启服务器后要再跑一次；已经在跑会直接跳过）：

```bash
bash /home/kjl/Evo-Depth/Metaworld-evaluation/start_mujoco_desktop.sh
```

笔记本上四个查看器各开一个网页，窗口会铺满浏览器。密码都用登录密码。easy 是 `http://192.168.2.1:6080/vnc.html?resize=scale&autoconnect=1`，medium 是 `6081`，hard 是 `6082`，very_hard 是 `6083`，后面都带 `?resize=scale&autoconnect=1`。例如只看 easy：

```bash
source /home/kjl/Evo-Depth/Metaworld-evaluation/.venv-metaworld/bin/activate
cd /home/kjl/Evo-Depth/Metaworld-evaluation
export MUJOCO_GL=egl
DISPLAY=:1 bash ./test_metaworld.sh ./logs ws://127.0.0.1:9000 --target_level easy --run_name mt50_easy --viewer
```



## 前置工作

Server 环境已经在 `/home/kjl/Evo-Depth/Evo_depth/.venv`。下面只在 client 环境或权重还不存在时做一次。


|        | 目录                                         | 环境                |
| ------ | ------------------------------------------ | ----------------- |
| Server | `/home/kjl/Evo-Depth/Evo_depth`            | `.venv`           |
| Client | `/home/kjl/Evo-Depth/Metaworld-evaluation` | `.venv-metaworld` |
| 权重     | `/home/kjl/checkpoint/metaworld`           |                   |




### 1. Client 环境

不要用 server 的 `.venv`，也不要用 LIBERO 的 Python 3.8 环境。

```bash
cd /home/kjl/Evo-Depth/Metaworld-evaluation
uv venv --python 3.10 .venv-metaworld
source .venv-metaworld/bin/activate
uv pip install -r requirements-metaworld.txt
uv pip install 'mujoco>=3.3,<3.17'
```

`mujoco` 3.17 的焊接参数是 12 个数，MetaWorld 3.0.0 仍写入 11 个数，环境会在创建时失败。缺 GL 库时再装：

```bash
sudo apt-get install -y libgl1 libglib2.0-0
```



### 2. 权重

目录里要有 `config.json`、`norm_stats.json`、`checkpoint.json`、`mp_rank_00_model_states.pt`。

```bash
export HF_ENDPOINT=https://hf-mirror.com
hf download MINT-SJTU/EVO-Depth-MetaWorld --local-dir /home/kjl/checkpoint/metaworld
```

`EVO_DEPTH_CKPT_DIR=/home/kjl/checkpoint/metaworld`。四个难度组都指这一份。


| 端口   | 卡     | 难度        | 任务数 | 预览   |
| ---- | ----- | --------- | --- | ---- |
| 9000 | GPU 0 | easy      | 28  | 8090 |
| 9001 | GPU 0 | medium    | 11  | 8091 |
| 9002 | GPU 1 | hard      | 6   | 8092 |
| 9003 | GPU 1 | very_hard | 5   | 8093 |


Client 会在 `--log_dir` 下再套一层 `--run_name`。结果是 `logs/<run_name>/eval.txt`，视频在 `logs/<run_name>/videos/`。单组跑完，成功率看该文件末尾的 `Overall (all trials)`。`Average of four difficulty buckets` 会把没跑的组当成 0，只在 `--target_level all` 时才有意义。

## 正式评测

先贴 server。四个日志都出现 `Evo_depth server running` 后再贴 client。easy 任务最多，最慢。

```bash
source /home/kjl/Evo-Depth/Evo_depth/.venv/bin/activate
cd /home/kjl/Evo-Depth/Evo_depth
kill $(cat /home/kjl/evo_plus_pids) 2>/dev/null || true
kill $(cat /home/kjl/evo_mt50_pids) 2>/dev/null || true
rm -f /home/kjl/evo_mt50_pids
export HF_ENDPOINT=https://hf-mirror.com
export EVO_DEPTH_CKPT_DIR=/home/kjl/checkpoint/metaworld
for spec in 0:9000 0:9001 1:9002 1:9003; do
  gpu=${spec%%:*}; port=${spec##*:}
  CUDA_VISIBLE_DEVICES=$gpu EVO_DEPTH_SERVER_PORT=$port nohup python scripts/Evo_depth_server.py > /home/kjl/evo_server_mt50_${port}.log 2>&1 &
  echo $! >> /home/kjl/evo_mt50_pids
done
tail -f /home/kjl/evo_server_mt50_9000.log
```



### 脚本

`run_mt50_clients.sh` 会自己再激活一次 client 环境。第一个参数是网页预览，第二个是 MuJoCo 查看器，都是 `on` 或 `off`。不写就是预览开、查看器关。查看器为 `on` 时会先跑 `start_mujoco_desktop.sh`。四路各一个网页，密码都用登录密码：

| 难度 | 查看器 |
| --- | --- |
| easy | `http://192.168.2.1:6080/vnc.html?resize=scale&autoconnect=1` |
| medium | `http://192.168.2.1:6081/vnc.html?resize=scale&autoconnect=1` |
| hard | `http://192.168.2.1:6082/vnc.html?resize=scale&autoconnect=1` |
| very_hard | `http://192.168.2.1:6083/vnc.html?resize=scale&autoconnect=1` |

开预览，关查看器：

```bash
source /home/kjl/Evo-Depth/Metaworld-evaluation/.venv-metaworld/bin/activate
cd /home/kjl/Evo-Depth/Metaworld-evaluation
export MUJOCO_GL=egl
bash ./run_mt50_clients.sh
```

关预览，关查看器：

```bash
source /home/kjl/Evo-Depth/Metaworld-evaluation/.venv-metaworld/bin/activate
cd /home/kjl/Evo-Depth/Metaworld-evaluation
export MUJOCO_GL=egl
bash ./run_mt50_clients.sh off
```

开预览，开查看器：

```bash
bash /home/kjl/Evo-Depth/Metaworld-evaluation/start_mujoco_desktop.sh
source /home/kjl/Evo-Depth/Metaworld-evaluation/.venv-metaworld/bin/activate
cd /home/kjl/Evo-Depth/Metaworld-evaluation
export MUJOCO_GL=egl
bash ./run_mt50_clients.sh on on
```

关预览，开查看器：

```bash
bash /home/kjl/Evo-Depth/Metaworld-evaluation/start_mujoco_desktop.sh
source /home/kjl/Evo-Depth/Metaworld-evaluation/.venv-metaworld/bin/activate
cd /home/kjl/Evo-Depth/Metaworld-evaluation
export MUJOCO_GL=egl
bash ./run_mt50_clients.sh off on
```

| 命令 | 网页预览 8090–8093 | 四个查看器网页 6080–6083 |
| --- | --- | --- |
| `run_mt50_clients.sh` | 开 | 关 |
| `run_mt50_clients.sh off` | 关 | 关 |
| `run_mt50_clients.sh on on` | 开 | 开 |
| `run_mt50_clients.sh off on` | 关 | 开 |

开预览时四路画面各开一个浏览器标签：

| 难度 | 预览 |
| --- | --- |
| easy | `http://192.168.2.1:8090/` |
| medium | `http://192.168.2.1:8091/` |
| hard | `http://192.168.2.1:8092/` |
| very_hard | `http://192.168.2.1:8093/` |

停掉这次脚本开的四路 client。server 和虚拟桌面留着。

