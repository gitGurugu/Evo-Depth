# LIBERO 评测

四个 suite 共用下面的环境和权重。换 suite 先停掉正在跑的 server，再换 `EVO_DEPTH_CKPT_DIR` 重启。启动前要设 `HF_ENDPOINT`，否则加载 InternVL3 时会去连 `huggingface.co` 并超时。日志里出现 `Evo_depth server running at ws://0.0.0.0:9000` 后再开 client。

## 前置工作

仓库和两个环境都已经在机器上。`libero` 装在 client 环境里，不用再 clone 一份 LIBERO 仓库。跑实验只激活环境。

| | 目录 | 环境 |
| --- | --- | --- |
| 仓库 | `/home/kjl/Evo-Depth` | |
| Server | `/home/kjl/Evo-Depth/Evo_depth` | `.venv` |
| Client | `/home/kjl/Evo-Depth/LIBERO-evaluation` | `.venv-libero` |

下面三段只在对应目录或环境还不存在时做一次。

### 拉取项目

```bash
cd /home/kjl
git clone https://github.com/MINT-SJTU/Evo-Depth.git
```

### Server 环境

```bash
cd /home/kjl/Evo-Depth/Evo_depth
uv venv --python 3.10 .venv
source .venv/bin/activate
uv pip install -r requirements.txt
MAX_JOBS=64 uv pip install -v flash-attn --no-build-isolation
uv pip install --no-build-isolation "git+https://github.com/nerfstudio-project/gsplat.git@0b4dddf04cb687367602c01196913cde6a743d70"
```

### LIBERO client 环境

`libero` 是 `.venv-libero` 里的包。不要用 server 的 `.venv` 跑 client。

```bash
cd /home/kjl/Evo-Depth/LIBERO-evaluation
uv venv --python 3.8.13 .venv-libero
source .venv-libero/bin/activate
uv pip install torch==1.11.0+cu113 torchvision==0.12.0+cu113 torchaudio==0.11.0 --extra-index-url https://download.pytorch.org/whl/cu113
uv pip install websockets
# 在 LIBERO 仓库里装进当前环境：uv pip install -r requirements.txt && uv pip install -e .
```

### 下载权重

四个 suite 一次下完。每个目录里要有 `config.json`、`norm_stats.json`、`mp_rank_00_model_states.pt`。

```bash
export HF_ENDPOINT=https://hf-mirror.com
hf download MINT-SJTU/EVO-Depth-LIBERO --local-dir /home/kjl/checkpoint \
  --include "libero_spatial/**" "libero_goal/**" "libero_object/**" "libero_10/**"
```

| suite | `EVO_DEPTH_CKPT_DIR` |
| --- | --- |
| libero_spatial | `/home/kjl/checkpoint/libero_spatial` |
| libero_goal | `/home/kjl/checkpoint/libero_goal` |
| libero_object | `/home/kjl/checkpoint/libero_object` |
| libero_10 | `/home/kjl/checkpoint/libero_10` |

## libero_spatial

```bash
# 终端 1：server
source /home/kjl/Evo-Depth/Evo_depth/.venv/bin/activate
cd /home/kjl/Evo-Depth/Evo_depth
pkill -f 'python scripts/Evo_depth_server.py' || true
export HF_ENDPOINT=https://hf-mirror.com
export EVO_DEPTH_CKPT_DIR=/home/kjl/checkpoint/libero_spatial
export EVO_DEPTH_SERVER_PORT=9000
nohup python scripts/Evo_depth_server.py > /home/kjl/evo_server.log 2>&1 &
tail -f /home/kjl/evo_server.log

# 终端 2：client
source /home/kjl/Evo-Depth/LIBERO-evaluation/.venv-libero/bin/activate
cd /home/kjl/Evo-Depth/LIBERO-evaluation
bash ./test_libero.sh ./logs/libero_spatial libero_spatial ws://127.0.0.1:9000
```
