# VLA-Arena 评测

VLA-Arena 是 11 个 suite、170 个任务的评测，分 Safety、Distractor、Extrapolation、Long Horizon。每个 suite 有 L0、L1、L2。策略用 Evo-Depth 的 Arena 权重，不要用 LIBERO 或 MetaWorld 的 checkpoint。11 个 suite 共用这一份权重和一个 server。

默认每个任务 10 条 episode，动作块执行 10 步，种子 27。不传 `--max_episode_steps` 时，普通 suite 最多 300 步，`long_horizon` 最多 600 步。下面的命令传了 300，长程任务也会在 300 步停。

不要动 `.venv`、`.venv-libero`、`.venv-libero-plus`、`.venv-metaworld`。VLA-Arena 用单独的 `.venv-vla-arena`，Python 必须是 3.11。先停掉占着 9000 的 server。停进程只杀下面写进 pid 文件的那一个 PID。

本目录的 `test_vla_arena.sh` 调用的是 `vla_arena/vla_arena_client.py`，文件实际在 `vla_arena_client.py`，而且有几行反斜杠后面带了空格，换行会断掉。用本文的 python 命令。

| suite | 类别 | L0 | L1 | L2 |
| --- | --- | --- | --- | --- |
| `safety_static_obstacles` | Safety | 5 | 5 | 5 |
| `safety_cautious_grasp` | Safety | 5 | 5 | 5 |
| `safety_hazard_avoidance` | Safety | 5 | 5 | 5 |
| `safety_state_preservation` | Safety | 5 | 5 | 5 |
| `safety_dynamic_obstacles` | Safety | 5 | 5 | 5 |
| `distractor_static_distractors` | Distractor | 5 | 5 | 5 |
| `distractor_dynamic_distractors` | Distractor | 5 | 5 | 5 |
| `extrapolation_preposition_combinations` | Extrapolation | 5 | 5 | 5 |
| `extrapolation_task_workflows` | Extrapolation | 5 | 5 | 5 |
| `extrapolation_unseen_objects` | Extrapolation | 5 | 5 | 5 |
| `long_horizon` | Long Horizon | 10 | 5 | 5 |

全量是 170 个任务乘 10 条 episode。先跑冒烟，日志里出现 `Connected to Server` 和一条 `Episode 1: Success` 或 `Episode 1: Failure` 再开全量。

### 1. 拉取 VLA-Arena

Client 从这份克隆里读 bddl 和资源。不要只 `pip install` 一个不带文件的包。

```bash
cd /home/kjl/Evo-Depth/VLA-Arena-evaluation
git clone https://github.com/PKU-Alignment/VLA-Arena.git VLA-Arena
```

克隆完成后应有 `VLA-Arena/vla_arena/vla_arena/bddl_files` 和 `VLA-Arena/vla_arena/vla_arena/assets`。缺资源时再在 client 环境里执行：

```bash
export HF_ENDPOINT=https://hf-mirror.com
vla-arena.download-tasks install-all --repo vla-arena/tasks
```

### 2. Client 环境

不要用 server 的 `.venv`。`vla-arena` 要求 Python 3.11。

```bash
cd /home/kjl/Evo-Depth/VLA-Arena-evaluation
uv venv --python 3.11 .venv-vla-arena
source .venv-vla-arena/bin/activate
cd VLA-Arena
```

无显示器时渲染用 `MUJOCO_GL=egl`。缺 GL 库时再装：

```bash
sudo apt-get install -y libgl1 libglib2.0-0
```

目录里要有 `config.json`、`norm_stats.json`、`checkpoint.json`、`mp_rank_00_model_states.pt`。仓库根就是 checkpoint，没有 suite 子目录。

## 冒烟

只跑 `safety_static_obstacles` 的每个任务 1 条 episode。日志出现 `Evo_depth server running at ws://0.0.0.0:9000` 后再开 client。Client 日志出现 `Connected to Server: ws://127.0.0.1:9000` 才算连上。

```bash
# 终端 1：server
source /home/kjl/Evo-Depth/Evo_depth/.venv/bin/activate
cd /home/kjl/Evo-Depth/Evo_depth
kill $(cat /home/kjl/evo_arena_pid) 2>/dev/null || true
rm -f /home/kjl/evo_arena_pid
export HF_ENDPOINT=https://hf-mirror.com
export EVO_DEPTH_CKPT_DIR=/home/kjl/checkpoint/arena
export EVO_DEPTH_SERVER_PORT=9000
nohup python scripts/Evo_depth_server.py > /home/kjl/evo_server_arena.log 2>&1 &
echo $! > /home/kjl/evo_arena_pid
tail -f /home/kjl/evo_server_arena.log
```

```bash
# 终端 2：client
source /home/kjl/Evo-Depth/VLA-Arena-evaluation/.venv-vla-arena/bin/activate
cd /home/kjl/Evo-Depth/VLA-Arena-evaluation
export MUJOCO_GL=egl
python vla_arena_client.py \
  --execution_horizon 10 \
  --seed 27 \
  --num_episodes_per_task 1 \
  --task_suite_names safety_static_obstacles \
  --server_url ws://127.0.0.1:9000 \
  --log_out_dir ./logs/smoke_safety_static \
  --save_video_mode all \
  --max_episode_steps 300
```

冒烟结果在 `logs/smoke_safety_static/log_file.txt`。结束时日志里有 `Statistics saved to:`，旁边有 `statistics.json`。视频在 `logs/smoke_safety_static/video/safety_static_obstacles/L0/`，文件名是 `task<编号>_ep0_success.mp4` 或 `task<编号>_ep0_failure.mp4`。

## 全量

Server 不用换权重，冒烟那个进程还在就继续用。已经停了就再跑一遍上面的终端 1。Client 去掉 `--task_suite_names`，每个任务改回 10 条。不传 suite 时会跑 `SUITE_CATEGORIES` 里、并且仿真包能找到的全部 suite。

```bash
source /home/kjl/Evo-Depth/VLA-Arena-evaluation/.venv-vla-arena/bin/activate
cd /home/kjl/Evo-Depth/VLA-Arena-evaluation
export MUJOCO_GL=egl
python vla_arena_client.py \
  --execution_horizon 10 \
  --seed 27 \
  --num_episodes_per_task 10 \
  --server_url ws://127.0.0.1:9000 \
  --log_out_dir ./logs/exp_h10_s27 \
  --save_video_mode all \
  --max_episode_steps 300
```

结果在 `logs/exp_h10_s27/log_file.txt` 和 `logs/exp_h10_s27/statistics.json`。视频在 `logs/exp_h10_s27/video/<suite>/L0|L1|L2/`。日志末尾有总成功率，以及四个类别、每个 suite、每一级的成功率。

只跑某几个 suite 时，名字接在 `--task_suite_names` 后面，用空格分开：

```bash
python vla_arena_client.py \
  --execution_horizon 10 \
  --seed 27 \
  --num_episodes_per_task 10 \
  --task_suite_names safety_static_obstacles long_horizon \
  --server_url ws://127.0.0.1:9000 \
  --log_out_dir ./logs/two_suites \
  --save_video_mode none \
  --max_episode_steps 300
```

`--save_video_mode none` 不存视频。默认的光照、颜色、噪声、相机偏移都是关的，冒烟和全量都不要加这四个开关。
